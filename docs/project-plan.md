# 프로젝트 계획

## 목표와 범위

**On-Device AI 기반 차량 운전자 상태 분석 및 개인화 서비스**를 개발합니다. 운전 중 운전자의 특이사항을 판단하는 AI가 중심이며, 생체신호를 주요 입력으로 사용하고 차량 CAN은 보조 정보로 활용합니다.

| 항목 | 상태 |
| --- | --- |
| 생체·CAN 전처리 및 상태 AI 판단 | 개발 목표 |
| 오프라인 임베디드 연속 추론 | 개발 목표; 보드 미정 |
| 상태 4단계 분류 | 착수발표의 초기 목표; 최종 라벨 미정 |
| 운전자별 Baseline 및 로컬 프로필 | 목표로 검토; 후속 질의에서는 가능하다면 구현 |
| HMI 및 서비스 연계 | 권장 사항; 최종 범위 미정 |
| 파일 Replay | 실시간 입력 확보가 어려울 경우 지원 계획 |

## 역할 분담

| 팀원 | 담당 | 산출물 계획 |
| --- | --- | --- |
| 김균도 | 팀장 · 서비스 / HMI | 일정, 보고서·발표 자료, HMI 및 팀 인터페이스 |
| 서동균 | 데이터 / 전처리 | 시간 동기화, 노이즈 제거, 특징 추출 |
| 문민규 | AI 모델링 | 상태 분류 모델, 개인화 Baseline 및 변화량 판단 |
| 양은철 | 임베디드 / 경량화 | 모델 경량화, 보드 이식, 추론 파이프라인 및 오프라인 검증 |

## 기술 선정 상태

| 영역 | 후보 및 방향 | 상태 |
| --- | --- | --- |
| 입력 | ECG, PPG, CAN; 실시간 / Replay | 데이터 사양 확인 필요 |
| 전처리 | 노이즈 저감, 시간 동기화, HRV·운전패턴 특징 | Window 및 세부 방식 미정 |
| 모델 | 생체 중심 상태 판단 및 보조 차량 특징 결합 | 구조·학습 방식 미정 |

| 런타임 | ONNX Runtime / TensorFlow Lite | 후보; 미선정 |
| 서비스 | HMI, 알림 및 개인화 연계 | 구현 범위 미정 |

## 다음 작업

아래 체크리스트는 완료 여부를 확인하기 위한 항목이며 자료만으로 완료 처리하지 않았습니다.

- [ ] 제공 데이터 및 PPG 보정 로직 수령 여부 확인.

- [ ] 모델 비교와 평가 방법, 완료 기준 합의.
- [ ] 운전자별 프로필 관리와 Baseline 방식 선정.

- [ ] HMI와 서비스 연계 범위 합의.
