# UL-DD 정리 (2026-11-16)

원본: `Downloads/CSV_Files.zip` (188 MB, 풀면 582 MB). 풀어 둔 곳은 `Downloads/datasets/ULDD/CSV_Files/CSV_Files/<참가자>/<세션>/`. DUA 상 재배포 금지라 저장소에는 원본을 올리지 않는다.

## 구성

- 참가자 19명 (A~S).
- 세션 35개
  - A = 각성 세션 19개
  - D = 졸음 세션 16개 (C, F, L 은 D 없음)
- 세션 길이 40분. 예외: A_D 35.7분, N_D 39.3분.
- 파일에 머리글(시작 시각·샘플링 행)이 없다. 샘플링은 줄 수 ÷ 2,400초로 확인했다.

| 파일 | 내용 | 실제 샘플링 | 비고 |
| --- | --- | --- | --- |
| BVP | E4 손목 PPG | **64 Hz** | 논문의 4 Hz 표기는 오기. 우리 맥박 검출 심박이 E4 HR 파일과 1 bpm 안으로 일치 |
| HR | E4 계산 심박 | 1 Hz | |
| IBI | E4 박동 간격 (시각, 간격) | 불규칙 | 많은 세션이 정확히 1,200줄에서 잘려 있음, 시각이 2,400초를 넘는 세션 있음, J_A 빈 파일 → **쓰지 않고 BVP 에서 다시 뽑는다** |
| ACC | 3축 가속도 | 32 Hz | |
| EDA | 피부 전도 | 4 Hz | |
| TEMP | 피부 온도 | 4 Hz | |
| O2M | 산소포화도 측정기 (SpO2, 맥박, 품질 추정값) | 0.5 Hz | 2열 맥박이 E4 HR 과 일치 |
| LGP / RGP | 왼손·오른손 핸들 악력 | 3 Hz | |
| Labels | KSS 10개 | 4분마다 | 0.5 단위 값 있음 (6.5, 7.5) |
| Telemetry (D 와 대부분의 A) | 시뮬레이터 heading, pitch, roll, speed, rpm, gear | 60 Hz | 조향각·차선 위치는 없음. A_A 는 없음. 시각이 33초부터 시작해 E4 와 정렬은 확인 필요 |

- **ECG 는 없다.**

## 라벨

- 각성 세션 (A): KSS 1~6, 세션 안에서 서서히 오름 (예: 1→4).
- 졸음 세션 (D): KSS 5~9, 대부분 6 → 8~9 로 오름.
- 우리 규칙(KSS ≥ 7 졸음, ≤ 5 정상)을 쓰면 A 세션은 거의 정상, D 세션은 중반 이후 졸음이 된다.
  - 같은 사람의 두 세션을 비교할 수 있다는 것이 장점이다.
  - 세션 간 비교는 측정일·시간대 차이와 섞여 있다는 것이 단점이다.

## 신호 품질 (BVP 8명 16세션 표본)

- 우리 PPG 박동 검출 기준 이상 간격 11~48% (중앙값 약 27%). 손목 PPG 라 WESAD 손목 BVP 와 비슷하게 거칠다.
- BVP 로 잰 RMSSD 가 100~160 ms 로 크다. 실측 3차와 같은 맥박 지터 문제이고, 짧은 변동 HRV 는 믿기 어렵다.
- 심박 자체는 E4 HR 과 잘 맞는다.

## 우리 파이프라인에 넣는 방법

1. **어댑터 (`adapters/uldd.py`):**
   - 참가자마다 A·D 두 세션, `ppg` = BVP 64 Hz
   - KSS 를 4분 구간 라벨로 펼침
   - 기준은 A 세션 앞 5분 (`is_rest` 또는 `baseline_range`)
   - 텔레메트리는 CAN 대용 채널로 함께 보관
2. **용도:**
   - 학생 PPG 경로의 **첫 공개 졸음 검증셋**. 지금까지 PPG 경로는 교사 일치도로만 확인했다.
   - CAN 규칙 시험용 (speed, heading 변화). 조향각이 없어 차선 이탈 규칙은 못 만든다.
3. **주의:**
   - 손목 PPG 지터 때문에 PRV 짧은 변동 특징은 끄거나 가중을 낮춰야 할 가능성이 크다 (실측 3차 분석과 같은 결론).
   - IBI 파일은 쓰지 않는다.
