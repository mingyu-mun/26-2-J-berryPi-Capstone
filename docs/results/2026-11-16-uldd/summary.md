# UL-DD 학생 PPG 경로 평가 (2026-11-16)

규칙: `docs/dataset-ul-dd.md` 평가 규칙 (결과 보기 전 고정). 원본·창별 점수는 재배포 금지라 올리지 않는다.

| 조건 | M1 (q ≤ 30%, 창 2,890) | 95% 구간 | M1 (유효 창 871) |
| --- | --- | --- | --- |
| P-full (현재 PPG 대체 판정) | 0.587 | [0.487, 0.698] | 0.595 |
| P-noshort (짧은 변동 HRV 끔) | **0.737** | [0.606, 0.863] | 0.701 |
| P-hr (심박 계열만 + 인코더) | **0.748** | [0.624, 0.870] | 0.740 |
| P-enc (파형 인코더만) | 0.734 | [0.586, 0.857] | 0.736 |
| R-dev (학습 없는 규칙, PRV) | 0.734 | [0.608, 0.868] | 0.744 |

- 판정: P-noshort, P-hr, P-enc, R-dev 의 M1 구간 하한이 0.5 보다 크다 → PPG 경로로 졸음 구분 가능. 현재 P-full 은 하한이 0.5 아래.
- P-noshort − P-full: +0.150 [+0.058, +0.259] (q ≤ 30%), +0.107 [−0.033, +0.241] (유효 창).
- 주의:
  - 각성 세션과 졸음 세션은 다른 날 측정이라, 같은 경과 시간에서 비교해도 "수면 부족 세션 vs 정상 세션" 차이가 섞인다.
  - 학생이 규칙(R-dev)보다 낫지는 않았다.
