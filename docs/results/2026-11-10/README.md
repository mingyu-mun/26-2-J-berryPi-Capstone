## 3. 학습 없는 규칙 (별도 계산)

개인 정규화 z 를 시험 데이터셋을 뺀 나머지로 fit (MSPC 는 나머지 데이터셋의 정상 창으로 PCA) 하고, 점수 그대로 AUROC 를 쟀다. 값은 1장 표에 포함. 계산 코드는 `PersonalNormalizer.transform` 출력(`z_*`, `az_*`, `dev_*`, `mspc_*`) 을 점수로 쓴 것.
