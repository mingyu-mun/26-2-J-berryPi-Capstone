# PhysDrive 오경보 점검 (2026-11-17)

- 데이터: 48명, 세션 236개 (기준 세션 제외), 창 6,846개. 실차 주행, 졸음 라벨 없음 → 전부 정상 상태로 가정.
- 신호: ECG·BVP 모두 명목 30 Hz.
  - ECG 는 R파 이상 간격 27~36% 로, 유효 창이 18% 뿐이다.
  - PPG 유효 창은 73% 이다.
- 기준: 참가자의 첫 세션 (보통 A1) 0~300초. 추론은 `scripts/infer_bundle.py --teacher` 로 했다 (최종 학생 번들).

- "짧은 변동 끔" 의 큰 감소는 점수 척도가 바뀐 탓이 크다. 같은 민감도로 맞추면 창 경보는 36% → 29% 정도만 준다.
- 공개 데이터 정상 창 경보 (14%) 보다 2배 이상 높다. 원인 후보:
  - 실차 진동·30 Hz 신호
  - 세션마다 주행 조건이 달라 첫 세션 기준과 차이가 남
  - 정상 상태 가정 자체를 확인할 수 없음
