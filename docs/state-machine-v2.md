# 상태 머신 v2 설계 초안: 학생 S1-EP 출력 + 잡음 오경보 억제

작성 2026-11-13. 상태: **초안 (사용자 수정 대기)**. 기존 v0.3 (`docs/state-machine.md`) 의 구조(10초 판정, 3단계, 히스테리시스)는 유지하고, 입력을 학생 S1-EP 로 바꾸고 잡음 대응을 추가한다.

## 0. 배경과 목표

- 학생 S1-EP 는 공개 데이터에서 졸음 판정력 (M1 0.668) 과 스트레스 억제 (S1 0.149) 를 확인했다.
- 실측 1차 녹음(ECG 이상 간격 15%)에서는 정상 상태인데 경보가 47% 나왔다. 원인은 잡음이었다.
  - 튀는 R파가 HRV 특징을 흔든다.
  - 기준 구간 자체가 잡음에 오염된다.
- 모델 입력에서 RR 을 지우는 방법(부록 A)은 공개 데이터 판정력을 잃어서 미채택했다. 그래서 **모델은 그대로 두고, 판정 후단에서 잡음을 다룬다.**
- 목표:
  - 잡음으로 인한 짧은 경보를 걸러낸다.
  - 기준 구간 오염을 막는다.
  - 졸음처럼 느리게 지속되는 변화는 놓치지 않는다.

## 1. 전체 흐름

```text
[시작] 기준 수집 단계 (5분, 품질 조건) ── 실패 ──▶ "기준 재측정" 안내, 최대 10분까지 연장
   │ 성공
10초마다 새 창 (최근 30초)
 → ① 창 판정 (품질)        ── 둘 다 불량 ──▶ -1 (판정 불가, 단계 유지)
 → ② 채널 선택             (ECG 불량·PPG 양호 → PPG 대체 판정, 신뢰도 낮춤)
 → ③ 학생 점수 p_t, 신뢰도 c_t
 → ④ 튀는 값 제거 (최근 3창 중앙값)
 → ⑤ 신뢰도 가중 누적 점수 s_t
 → ⑥ 잡음 급증 동결        (잡음과 점수가 함께 뛰면 상승 전이 보류)
 → ⑦ 단계 전이 (정상 / 주의 / 졸음), 지속 시간 조건
 → ⑧ CAN 교차 확인         (졸음 단계 확정 조건, 규칙 기반, 별도 규격)
 → ⑨ 장기 감시             (품질 좋은데 경보가 오래 지속되면 "기준 재확인" 제안)
```

## 2. 기준 수집 단계 (실측 1차 문제 대응)

| 항목 | 기본값 | 내용 |
| --- | --- | --- |
| 길이 | 5분 | 교사·학생 학습과 같은 기준 길이 |
| 시작 대기 | 60초 | 착석·센서 안정화 시간은 기준에서 뺀다 |
| 창 품질 조건 | ECG 이상 간격 q_ecg ≤ 5% | 이 조건을 만족하는 창만 기준에 쓴다 |
| 최소 깨끗한 창 | 20개 (기준 5분의 약 70%) | 못 채우면 기준 구간을 10초씩 뒤로 늘린다 |
| 최대 대기 | 10분 | 그래도 못 채우면 "센서 재부착 후 기준 재측정" 안내, 판정 시작하지 않음 |

- 기준 벡터는 깨끗한 창들의 중앙값이다. RR 특징과 학생 인코더 g(x) 둘 다 해당한다.
- 실측 1차는 어느 5분을 골라도 이상 간격이 8.5% 이상이었다. 이 규칙이면 판정을 시작하지 않고 재측정을 안내했을 것이다.

## 3. 창 판정과 채널 선택

창마다 품질 지표를 계산한다.

| 지표 | 정의 |
| --- | --- |
| q_ecg | 30초 창 안 ECG RR 이상 간격 비율 (0.3~2초 밖, 또는 주변 중앙값 ±20%) |
| q_ppg | 같은 정의, PPG 맥박 간격 |
| Δ_HR | \|ECG HR − PPG HR\| (bpm) |
| 기존 검사 | 평탄, 포화, 값 멈춤 (v0.3 그대로) |

| 경우 | 조건 (기본값) | 처리 |
| --- | --- | --- |
| 양호 | q_ecg ≤ 5% | S1-EP (ECG+PPG) 점수 사용, 신뢰도 c = 1 |
| ECG 다소 불량 | 5% < q_ecg ≤ 10% | S1-EP 사용, c = (10% − q_ecg) / 5% (선형으로 0~1) |
| ECG 불량, PPG 양호 | q_ecg > 10%, q_ppg ≤ 10%, 기존 검사 통과 | **PPG 대체 판정**: ECG 채널을 끄고 학생 PPG 경로 사용, c = 0.5 |
| 둘 다 불량 | 그 외 | -1 (판정 불가), 전이 계산에서 제외 |
| 센서 불일치 | Δ_HR > 10 bpm | 둘 중 이상 간격이 큰 쪽을 불량으로 보고 위 표 적용 |

- 신뢰도 c 는 **모델 입력을 바꾸지 않고** 상태 머신의 누적 속도만 조절한다. 그래서 부록 A 에서 확인한 판정력 손실이 생기지 않는다.
- PPG 대체 판정: 현재 학생은 PPG 만 넣어도 RR 특징을 ECG 에서 가져온다. 대체 판정에서는 PRV(PPG 맥박 간격) RR 특징으로 바꿔야 한다. 이건 구현할 때 확인할 항목이다 (8장).

## 4. 점수와 누적

- 학생 출력: logit ℓ_t, 확률 p_t = σ(ℓ_t). 동작점 θ = 공개 데이터 졸음 창 민감도 50% 지점 (현재 ℓ = −0.050, p ≈ 0.49).
- **튀는 값 제거:** p̃_t = 최근 유효 3창의 p 중앙값. 10초 창이 겹쳐 있어서, 잡음 덩어리 하나가 만드는 1~2창짜리 급등을 걸러낸다.
- **신뢰도 가중 EMA:** s_t = s_{t−1} + α · c_t · (p̃_t − s_{t−1}), α = 0.3. c_t 가 작으면 그 창은 누적 점수를 거의 움직이지 못한다.

## 5. 잡음 급증 동결

실측 1차 700~950초처럼 잡음 덩어리와 점수 급등이 동시에 오는 경우를 막는다.

- 조건: 최근 60초 q_ecg 평균이 직전 5분 평균보다 3%p 넘게 늘고, 같은 60초 동안 p̃ 가 0.3 넘게 올랐을 때.
- 처리: 60초 동안 **상승 전이만 보류**한다. 하강 전이와 점수 누적은 그대로 둔다.
- 졸음 자체가 움직임 잡음을 만들 수도 있다. 공개 데이터에서 잡음 창 비율이 졸음 창에서 더 높았다. 그래서 동결은 60초로 짧게 두고, 그 뒤에도 점수가 높으면 정상적으로 상승한다.

## 6. 단계 전이

| 기호 | 기본값 (실차용) | v0.3 (시연용) | 의미 |
| --- | --- | --- | --- |
| θ_on | 0.55 | 0.6 | s_t > θ_on 이면 상승 쪽 시간 누적 |
| θ_off | 0.40 | 0.4 | s_t < θ_off 이면 하강 쪽 시간 누적 |
| T_up(정상→주의) | 60 s | 10 s | 상승 쪽 누적이 이만큼 연속이면 주의 |
| T_up(주의→졸음) | 120 s | 10 s | 주의에서 이만큼 더 연속이면 졸음 후보 (8장 CAN 확인) |
| T_down | 60 s | 10 s | 하강 쪽 누적이 이만큼 연속이면 한 단계 하강 |
| T_hold | 60 s | 60 s | -1 이 이만큼 연속이면 측정 불가, 초기화 |

- 졸음은 수 분 단위로 진행된다. 실측 1차의 잡음 경보 덩어리는 대부분 30~90초였다. 그래서 주의까지 60초, 졸음까지 추가 120초의 지속을 요구한다.
- 시연용 설정(10초)은 그대로 남겨 두고, 설정 파일에서 프로필로 고른다.

## 7. 장기 감시 (기준 오염 대응)

- 최근 10분 동안 유효 창의 70% 이상이 θ 이상이고, 품질은 양호(q_ecg 평균 ≤ 3%)하며, CAN 에 졸음 징후가 없으면 "기준 재확인" 을 제안한다.
- 운전자가 수락하면 그 시점부터 5분을 새 기준으로 다시 수집한다. 2장의 규칙을 그대로 쓴다.
- 자동으로 기준을 바꾸지는 않는다. 실제 졸음을 기준으로 삼아 버리는 것을 막기 위해서다.

## 8. CAN 교차 확인 (별도 규격)

앞서 정한 대로 CAN 은 규칙 기반으로 생체 판정을 교차 확인하는 용도다.

- 주의 단계: 생체 점수만으로 올린다.
- 졸음 단계: 다음 중 하나가 있어야 확정한다.
  - CAN 졸음 징후: 차선 유지 흔들림, 조향 정지 후 급조향, 속도 변동 등 (규칙은 별도 규격)
  - 생체 점수가 졸음 후보 상태로 추가 3분 이상 지속
- CAN 이 없는 환경(실험실 실측)에서는 두 번째 조건만 쓴다.

## 9. 평가 계획 (조정 전에 고정)

| 데이터 | 지표 | 목표 (초안) |
| --- | --- | --- |
| 공개 4종 학생 LODO 점수 타임라인 | 졸음 구간 감지 지연 중앙값, 놓침 비율 | 지연 ≤ 5분, 놓침 ≤ v0.3 대비 +10%p |
| 공개 4종 정상 구간 | 시간당 오경보 (주의 이상 진입 횟수) | ≤ 1회/시간 |
| WESAD 스트레스·평상시 | 시간당 오경보 | ≤ 1회/시간 |
| 실측 1차 (잡음 많음) | 기준 수집 결과, 오경보 | 재측정 안내 (판정 시작 안 함) |
| 실측 2차 | 시간당 오경보 | ≤ 1회/시간 (정상 상태라는 전제) |
| 합성 잡음 주입 | 공개 정상 구간에 30~90초 잡음 덩어리를 넣었을 때 오경보 증가 | +0.5회/시간 이하 |

- 기본값(θ, T, α, 잡음 기준)은 공개 데이터 LODO 의 검증 fold 로만 맞춘다. 시험 데이터셋과 실측 녹음은 최종 평가에만 쓴다.
- 합성 잡음: 실측 1차에서 관찰한 형태를 RR 에 넣는다 (가짜 박동 삽입, 누락, 이상 간격 15%).

## 10. 구현 범위

- `src/driver_state/state_machine.py` 에 v2 클래스를 추가한다. v0.3 은 유지한다.
- 입력: 창별 학생 logit (S1-EP, PPG 경로), q_ecg, q_ppg, Δ_HR, 기존 품질 검사 결과.
- 출력: v0.3 필드에 다음을 추가한다.
  - `confidence`, `channel` (EP / PPG / none)
  - `frozen` (잡음 동결 여부)
  - `baseline_status` (수집 중 / 완료 / 재측정 필요)
- 평가 스크립트: 학생 LODO 점수(`out/student/student_scores.parquet`)와 실측 결과로 9장 지표를 계산한다.

## 11. 결정이 필요한 사항

1. 6장 지속 시간: 실차용 60초 / 120초가 적당한지, 시연용으로 더 짧게 볼지
2. 3장 PPG 대체 판정을 넣을지. 넣으면 PRV 기반 RR 특징 경로를 추가로 구현해야 한다.
3. 7장 "기준 재확인" 을 운전자에게 묻는 방식 (화면 / 음성 / 자동 안 함)
4. 9장 목표치 (특히 감지 지연 5분, 오경보 1회/시간)
