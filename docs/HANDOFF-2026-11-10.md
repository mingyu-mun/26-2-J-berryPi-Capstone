## 5. 핵심 발견

1. **"졸음"이 두 상태다.** KSS 졸음(졸음과 싸우는 상태)은 심박↑ (DROZY +3.5 bpm, 78%), EEG 졸음(잠에 빠져듦)은 심박↓ (MPD-DF −3.3 bpm, 84%). 헤드 하나는 다수 방향(심박↑)을 배웠다.
2. **v1 교사(rrnet)가 스트레스를 졸음으로 판정**: WESAD TSST 의 77% 가 졸음, P 중앙값 0.87.
3. **시간 효과가 섞여 있다.** 시간만으로 AdVitam 0.71, MPD-DF 0.79 를 맞힌다. 세션 안 시간 추세를 빼도 DD-DB rrnet 0.72, MPD-DF 규칙 0.70 은 남는다 → 약하지만 실제 신호 있음.
4. dev_core 규칙의 높은 점수는 "기준 이후 달라짐 + 시간 경과"를 잰 몫이 크다 (DD-DB 처럼 졸음·정상이 같은 시간대면 0.54).
5. 어댑터·RR 추출은 문제 없음 (AdVitam 저자 공개값과 평균 RR r = 0.997).
6. v1 교사로 학생 데이터 라벨링: MAUS 졸음 19.6%, CLAS 15.0%, WESAD 64.4% → 그대로 쓰지 않기로.

## 6. 사용자와 정한 원칙·결정

- 라벨 정의는 외부 기준(KSS ≥7, EEG 논문 정의, PVT 500 ms 등)으로 **결과 보기 전에 고정**. 점수를 보며 고치지 않는다 (과적합 방지).
- 규칙 기반이 아닌 **학습 모델**을 쓴다. 공개 데이터 LODO 는 비교용, 최종 판단은 자체 측정 데이터.
- **ECG·PPG 로 사전학습된 모델 + 추가 학습** 방식 채택 → NormWear (Apache 2.0, `mosaic-laboratory/normwear`, `model.safetensors` 775 MB만 사용, 약 2억 파라미터). M2AE(arXiv 2605.09579)는 가중치 미공개.
- 라즈베리파이에는 NormWear 를 올리지 않고 **작은 학생으로 증류**.
- 학생 학습은 하드 라벨 대신 **교사 확률(소프트 라벨)** 을 쓰는 방향.

## 7. 다음 실험: 교사 v2 (상세는 `docs/teacher-v2.md`)

```
30초 창 → NormWear(고정) → 768 → 128 투영 → x_t
지난 10분 토큰 20개 → Transformer 2층(d=128) → 맥락 c_t
c_t → 맥락 헤드 → 상황 4종 q (수면 박탈 / 장시간 주행 / 스트레스·과제 / 평상시)
[x_t ‖ c_t] → KSS 헤드 · EEG 헤드 · 버튼 헤드
게이트 g = softmax(M·q) → P(졸음) = Σ g_k σ(헤드_k)
```
- 손실: 헤드별 BCE + 결합 P BCE (WESAD TSST·읽기, CLAS 과제, MAUS n-back 을 정상 0 으로) + 맥락 CE + 데이터셋 적대 손실
- 비교: B0 rrnet, B1 dev_core, A1 헤드 1개, A2 라벨별 헤드, **A3 본안**, A4 적대 없음. 시드 3개
- 지표: LODO AUROC, 시간 추세 제거 AUROC, **WESAD TSST 오경보율**, 맥락 헤드 정확도, ECE, DROZY 참가자 5-fold
- 채택 기준: A3 가 A2 보다 +0.02 이상이고 TSST 오경보 감소
- **미결**: A5 (x_t 에 rrnet 인코더 64차원을 NormWear 특징과 함께 붙임) 를 비교에 추가할지 사용자 답 대기. 추가한다면 실험 전에 설계 문서 6장에 넣을 것
- 현실적 기대: 평균 0.65~0.68 + TSST 오경보 감소면 성공
