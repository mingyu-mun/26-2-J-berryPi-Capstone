# NormWear 표현으로 인코더 교체 1단계 규격

> 작성: 2026-11-12 · 실험 장소: 연구실 GPU 서버 (RTX 3090) · 기준 코드: `claude/project-thread-tbz3az` 의 `f2a0f10`
> 구조·조건·지표·판정은 **결과를 보기 전에 고정**한다. 바꾸면 9장에 날짜와 이유를 적고, 바꾼 뒤 평가는 한 번만 다시 한다.

## 0. 목적

지난 두 실험의 입력 표현(RR 요약 특징 36개, rrnet 인코더)을 **NormWear 사전학습 표현**으로 바꿔, 같은 학습·평가 틀에서 졸음 판별과 스트레스 오경보가 나아지는지 본다.
- teacher-pair 1단계 (`teacher-pair-stage1.md`): 쌍 학습 P0·P1·P2
- 생체 이상 점수 1단계 (`teacher-anomaly-stage1.md`): 방향 없는 학습 거리 F2 (R2·R3 의 rrnet 인코더 자리를 고정된 NormWear 로)

학습 규칙·라벨·LODO·지표 정의는 두 규격을 그대로 따른다. 바뀌는 것은 입력 표현뿐이다.

## 1. NormWear 표현 추출

| 항목 | 값 |
| --- | --- |
| 모델 | NormWear (Apache 2.0), `mosaic-laboratory/normwear` 의 `model.safetensors` 만 사용 (pickle 형식 체크포인트는 쓰지 않음). 가중치 고정 |
| 입력 신호 | **ECG 만** (교사 4종은 ECG 만 있음. WESAD 도 가슴 ECG 로 맞춤). 규약 폴더 `data.npz` 의 원 ECG |
| 전처리 | 공통 전처리와 같은 0.5–40 Hz 대역통과 후 **65 Hz 로 리샘플** (NormWear 사전학습 주기). 창마다 z-score |
| 구간 | 30초 창을 **6초 구간 5개**로 나눔 (사전학습 길이 388 표본 ≈ 6초). 구간마다 `get_embedding` → 패치 평균 768차원 |
| 창 표현 | 5개 구간 표현의 평균 → 768차원 e_t |
| 대상 창 | 교사 4종 전체 창, WESAD·CLAS·MAUS 전체 창, 그리고 **기준 구간 창** (기준 구간 [start, end] 안의 30초 창, 10초 이동) |

### 1.1 차원 축소 (고정, 학습 fold 와 무관)

- **CLAS·MAUS 창으로만** PCA 를 fit 한다 (두 데이터는 모든 fold 학습에 들어가고 어느 fold 에서도 시험되지 않으므로 정보가 새지 않는다).
- 세션마다 평균을 뺀 표현으로 fit ("세션 안에서 변하는 방향"). 32개 주성분.
- 모든 창과 기준 창을 그 32축에 사영 → `nw_00 … nw_31`.
- 기준 벡터: 참가자(`profile_key`)의 기준 창 사영값 중앙값 → `m_nw_00 …`. 기준 창이 없으면 그 참가자는 평가에서 빠짐.

## 2. 조건

### 2.1 쌍 학습 (teacher-pair 규격 그대로, 입력만 교체)

| ID | 입력 | 모델 |
| --- | --- | --- |
| P0N | NW 32 | P0 와 같은 창 BCE MLP (몸통 입력 차원만 32) |
| P1N | NW 32 | P1 (쌍, 헤드 1) |
| P2N | NW 32 | P2 (쌍, 헤드 2) |
| P1C | RR 36 + NW 32 (68) | P1 |

- 2장 변환: NW 열은 로그 없이 표준화·±5 자르기. 스케일 묶음 드롭은 RR 열에만 적용.
- 기준 차감 d = f(x_t) − f(x_ref) 그대로. tbin 150초.

### 2.2 방향 없는 학습 거리 (anomaly 규격 그대로, 입력만 교체)

| ID | 입력 z | 모델 |
| --- | --- | --- |
| F2N | (nw_t − m_nw) / σ_pop (32) | ‖W z‖, W ∈ R^{8×32}, 스트레스 음성 포함 |
| F2C | RR z 36 + NW z 32 (68) | ‖W z‖, W ∈ R^{8×68}, 스트레스 음성 포함 |

σ_pop: 학습 fold 교사 창의 참가자별 표준편차 중앙값 (PersonalNormalizer 와 같은 방식).

### 2.3 비교 기준 (재계산, 같은 평가 행)

B0 rrnet, B1 dev_core, 그리고 지난 실험의 RR 버전: P1 (쌍), F2 (거리).

## 3. 평가 행

교사 4종의 valid, y ≥ 0, `baseline_valid = 1`, NW 기준 벡터가 있는 창. 모든 비교 조건 점수가 유한한 창으로 맞춘다.

## 4. 지표

M1 (시간 층화 AUROC, 주 지표), M2, M4, M3 (DD-DB·MPD-DF), S1 (WESAD TSST 오경보, 민감도 50%), S2 (WESAD 평상시 오경보), ECE. 정의는 두 규격과 같다. 부트스트랩 2,000회 (시드 0, 참가자 단위). 쌍 학습 조건의 S1 은 teacher-pair 규격의 M5-3 과 같은 정의.

## 5. 판정 (결과 보기 전 고정)

- **NormWear 표현 효과 (쌍 학습)**: P1N − P1 의 M1 95% 구간 하한 > 0
- **NormWear 표현 효과 (거리)**: F2N − F2 의 M1 95% 구간 하한 > 0
- **결합 효과**: P1C − P1, F2C − F2 의 M1 95% 구간 하한 > 0
- **채택 후보**: M1 평균 ≥ max(B0, B1) − 0.01 이고 S1 < B1 이며 S1 차이 95% 구간 상한 < 0 인 조건 중 M1 최고. 없으면 채택 없음
- **미채택 시**: 공개 데이터 + 사전학습 표현으로도 졸음·스트레스 구분이 안 된다고 보고, CAN 규칙 보정과 자체 측정으로 넘어간다

## 6. 구현

- `scripts/normwear_embed.py` (서버): 1장 추출, `nw_embed_<dataset>.parquet` (row_id, 768) + 기준 창 표현, PCA 저장
- `src/driver_state/teacher/nw_features.py`: 사영·기준 벡터를 windows/profiles 에 `nw_*`·`m_nw_*` 열로 붙임
- pair_eval·anomaly 에 입력 열 목록을 바꿀 수 있는 옵션 추가 (기존 동작은 그대로)

## 7. 예상 시간 (RTX 3090)

추출: 약 10만 창 × 0.05초 ≈ 1.5시간. 학습: 쌍 4조건 × 시드 5 × 4 fold + 거리 2조건, MLP 라 수십 분.

## 8. 열린 질문

- ECG 를 65 Hz 로 낮추면 QRS 모양 정보가 줄어든다. NormWear 의 사전학습 주기를 따르는 쪽을 택했다.
- WESAD 비상업 조건 (이전과 같음).
