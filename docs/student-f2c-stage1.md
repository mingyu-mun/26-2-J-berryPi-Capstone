# 학생 라벨링·증류 1단계 설계 (교사 F2C)

작성 2026-11-12. 상태: 초안 (사용자 검토 대기). 결과를 보기 전에 판정 기준을 고정한다.

## 0. 목적과 전제

- 교사는 **F2C**로 확정한다 (docs/results/2026-11-12-normwear: M1 0.641, S1 0.410).
  - 점수: s = ‖W z‖, z = [RR z 36 ; NormWear z 32], W ∈ R^{8×68}
  - 확률: p = sigmoid(softplus(α)·s + b)
- 학생은 라즈베리파이에서 돈다. NormWear(약 1억 파라미터)는 올리지 않는다.
- 데이터 사정 (설계를 정하는 제약):
  - 졸음 정답이 있는 교사 데이터 4종(AdVitam, DD-DB, DROZY, MPD-DF)은 **ECG만** 있다.
  - PPG는 학생 데이터 3종(CLAS 60명, MAUS 22명, WESAD 15명)에만 있고, 이들에는 졸음 정답이 없다.
  - manD는 실효 표본율 문제로 계속 제외한다.
  - 따라서 PPG 학생은 정답으로 직접 평가할 수 없다. 교사 일치도와 ECG↔PPG 대응으로 간접 평가한다.

## 1. 라벨링 (교사 → 창별 라벨 표)

### 1.1 라벨 대상

| 데이터 | 창 수 | 라벨을 붙이는 교사 모델 | 누수 방지 |
| --- | --- | --- | --- |
| 교사 4종 | 약 4만 (평가 행) | LODO fold 모델 (그 데이터셋을 빼고 학습) | 기존 oof 그대로 |
| CLAS, MAUS | 13,339 / 3,668 | **최종 F2C**: 교사 4종 전체 + WESAD 스트레스 음성으로 학습 | 학습에 쓰지 않은 데이터 |
| WESAD | 7,039 | 최종 F2C, 단 WESAD 4 묶음 교차 (자기 묶음 스트레스 창은 학습에서 뺌) | 묶음 단위 |

- 시드 5개 평균이며, 교사 학습 규격은 그대로 둔다.
- 유효 창(valid)이고 기준 벡터(RR·NW)가 모두 있는 창만 라벨을 붙인다.

### 1.2 라벨 표 열 (`labels/f2c_labels.parquet`)

- `row_id`, `dataset_id`, `group`, `session_id`, `t_rel`
- `s` (거리), `p` (보정 확률), `s_seed_sd` (시드 간 표준편차, 불확실도)
- `z_rr[36]`, `z_nw[32]`: 교사 입력. 학생 특징 증류의 목표로 쓴다.
- `proj[8]` = W z: 교사의 8축 사영
- `cond`: other / task / stress / mixed
- `y`: 교사 데이터의 정답. 학생 데이터는 −1

### 1.3 인지 과제 구간

- 앞서 정한 대로 판단 보류 구간이다. 라벨은 붙이되 `cond = task`로 표시한다.
- 증류 학습에는 넣는다. 교사가 이 구간에서 낮은 점수를 내는 것도 배울 내용이기 때문이다.
- 졸음 평가 지표에서는 뺀다.

### 1.4 라벨 점검 (학습 전, 판정 아님)

- 데이터셋·조건별 p 분포와 p ≥ 0.5 비율. v1 교사는 WESAD 64%가 졸음으로 나왔고, 이번에 얼마나 줄었는지 본다.
- 시드 간 표준편차 분포.
- 참가자별 시간에 따른 s 곡선 몇 개를 그림으로 남긴다.

## 2. 학생 모델

교사 구조를 그대로 따르고, 비싼 부분(NormWear)만 작은 네트워크로 바꾼다. 교사의 W를 물려받기 때문에 "방향 없는 거리"라는 성질이 학생에도 남는다.

```
RR/PRV 특징 36 ──(개인 기준 z)──────────────┐
                                             ├─ z (68) ─ W (교사 값으로 시작) ─ ‖·‖ ─ s
ECG·PPG 30초 ─ 작은 1D CNN g ─ ẑ_nw (32) ──┘
                (기준 구간 창도 같은 g 로 → 기준 차감)
```

### 2.1 조건

| ID | 입력 | NW 부분 | 비고 |
| --- | --- | --- | --- |
| S0 | ECG RR 36 | 없음 (F2) | 신경망 없는 하한. 이미 M1 0.599 |
| S1-E | ECG RR 36 + ECG 파형 | g_E (ECG) | 주 후보 (ECG만) |
| S1-EP | ECG RR 36 + ECG·PPG 파형 | g_EP (두 채널, 채널 드롭아웃) | 주 후보 (PPG+ECG) |
| S1-P | PPG 맥박 간격(PRV) 36 + PPG 파형 | g_P (PPG) | PPG만 |
| S2-E | ECG 파형만 | 종단간 CNN이 p 를 바로 예측 | 비교: 특징 증류 대신 점수 증류 |

### 2.2 작은 인코더 g

- 입력: 30초 창, 64 Hz로 리샘플(1,920 표본), 창마다 z-score.
- 구조: 1D CNN 4블록(채널 16→32→64→64, 커널 7, stride 2, BN, GELU) → 전역 평균 → Linear(64, 32).
- 크기: 약 6만 파라미터, int8로 약 60 KB.
- 기준 벡터: 기준 구간 창들의 g 출력 중앙값. 기기에서는 운전 시작 5분 동안 한 번 계산한다.

### 2.3 손실

- L_feat = ‖(ẑ_nw − m̂_ref) − z_nw‖² : 교사의 NW z를 직접 맞춘다 (특징 증류).
- L_score = BCE(p_student, p_teacher) : 소프트 라벨. W, α, b는 교사 값으로 시작해 작은 학습률로 미세조정한다.
- L = L_feat + λ·L_score, λ = 0.5.
- 가중치는 데이터셋 균등 × 참가자 균등이다.

### 2.4 PPG 쪽 문제와 처리

- PPG 학생은 졸음 구간을 거의 보지 못한다. 학생 데이터에는 졸음이 드물기 때문이다.
- 처리 1. **교차 모달 증류**: CLAS·MAUS·WESAD에서는 같은 시각 ECG로 만든 교사 z_nw를 PPG 인코더의 목표로 쓴다. ECG가 보는 상태 변화를 PPG로 재현하게 한다.
- 처리 2. **S1-EP의 채널 드롭아웃** (PPG만 30%, ECG만 30%): 교사 데이터의 ECG 졸음 구간에서 배운 표현을 공유 몸통이 PPG 쪽으로도 쓰게 한다.
- PRV 특징: PPG 수축기 시작점(발끝) 간격으로 RR 특징 36개를 같은 코드로 계산한다. 같은 시각 ECG RR 특징과의 일치도를 함께 보고한다.

## 3. 학습·평가 분할

- **교사 데이터: LODO 4 fold.** 시험 데이터셋은 학생 학습에서도 뺀다. 그 fold의 교사 라벨(oof)로 학습하고, 정답 y로 평가한다.
- **학생 데이터: 참가자 단위 5 fold** (CLAS·MAUS·WESAD 각각). 시험 참가자의 창은 학습에서 뺀다.
- 시드 3개.

## 4. 지표

| 지표 | 대상 | 의미 |
| --- | --- | --- |
| M1 (시간 층화 AUROC) | 교사 4종, ECG 학생 | 정답 졸음 성능 (주 지표) |
| S1 / S2 | WESAD (ECG·PPG 각각) | 스트레스 / 평상시 오경보 (민감도 50% 임계) |
| 교사 일치도 | 학생 데이터 시험 참가자 | s 의 Spearman ρ, 교사 p 상위 20% 를 양성으로 둔 AUROC |
| PRV 일치 | CLAS·MAUS·WESAD | PRV vs HRV 특징 36개 상관 중앙값 |
| 기기 비용 | 라즈베리파이 (또는 ARM 추정) | 30초 창당 추론 시간, 메모리, 모델 크기 |

부트스트랩 2,000회, 참가자 단위, 빠른 쌍체 버전(`bootstrap_m1`).

## 5. 판정 (결과 보기 전 고정)

- **ECG 학생 채택**: S1-E 또는 S1-EP(ECG만 입력 평가)가 다음을 모두 만족하면 채택한다. 둘 다 통과하면 M1이 높은 쪽.
  - M1 ≥ F2C − 0.03 (= 0.611 기준)
  - M1 − S0 의 95% 구간 하한 > 0 (작은 인코더가 RR만 쓰는 것보다 낫다)
  - S1 ≤ 0.50
- **PPG 학생 채택**:
  - S1-P 또는 S1-EP(PPG만 입력)의 교사 일치 ρ ≥ 0.6
  - WESAD PPG S1 ≤ 0.55
- **기기 조건**: 창당 추론 100 ms 이하, 모델 1 MB 이하.
- **특징 증류 vs 점수 증류**: S1-E − S2-E 의 M1 차이를 보고한다 (판정 아님).
- **미채택 시**: S0(RR/PRV만 쓰는 F2)를 기기용 기본으로 두고, 자체 측정 데이터로 인코더를 다시 시도한다.

## 6. 구현 순서

1. `scripts/teacher.py f2c-label`: 최종 F2C 학습(WESAD 묶음 교차 포함) 후 라벨 표 저장. GPU 서버, 약 10분.
2. 라벨 점검 그림·표 (1.4).
3. `src/driver_state/student/`: PRV 추출, 파형 창 캐시(64 Hz, ECG·PPG), 인코더 g, 학습 루프.
4. 학생 학습·평가 (GPU 서버). 조건 5개 × fold × 시드 3, 약 1~2시간.
5. 비교 보고, ONNX/int8 내보내기, 라즈베리파이 시간 측정.

## 7. 열린 질문 (사용자 확인 필요)

1. 학생 주 형태를 **PPG+ECG(S1-EP)** 로 둘지, **ECG만(S1-E)** 으로 둘지. 현재 설계는 둘 다 돌리고 위 판정으로 고른다.
2. WESAD는 비상업 조건이다. 학생 학습에 넣으면 그 학생 모델도 비상업으로 묶인다. 캡스톤에서는 문제가 없지만, 이후 상용화를 고려하면 WESAD 없는 판도 함께 만들지 정해야 한다.
3. 상태 머신 연결(경보 임계, 지속 시간)은 2단계로 미룬다.
