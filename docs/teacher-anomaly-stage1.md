## 1. 데이터와 라벨

| 데이터 | 졸음(1) | 졸음 아님(0) | 쓰임 |
| --- | --- | --- | --- |
| AdVitam | KSS ≥ 7 (주행 앞·끝 5분) | KSS ≤ 5 | 학습·LODO 시험 |
| DROZY | KSS ≥ 7 (테스트 전체) | KSS ≤ 5 | 학습·LODO 시험 |
| DD-DB | 버튼 ±60초 | 버튼에서 600초 이상 | 학습·LODO 시험 |
| MPD-DF | EEG 단계 2~4 | 단계 0 | 학습·LODO 시험 |
| WESAD | — | **TSST 구간에 완전히 들어간 창** (`cond = stress`) | 참가자 4묶음, fold 마다 1묶음 시험 (4.3) |
| WESAD | — | 그 밖의 창 (`cond = other`: 명상·재미·읽기·사이 구간) | 학습 안 함. 시험 참가자의 평상시 오경보 (S2) |
| CLAS·MAUS | — | — | 사용 안 함 (판단 보류) |

창은 기존 그대로 (30초 창, 10초 이동, `windows.parquet` 유효 창). 시간 층 `tbin` 150초 (`teacher-pair-stage1.md` 11장).
평가 행: valid, y ≥ 0, `baseline_valid = 1`, 기준 타코그램(2.2)이 있는 창.

## 2. 입력

### 2.1 창 타코그램 (rrnet 과 같음)

창 중심 ±150초의 정상 RR 을 4 Hz 로 보간한 (2, 1200) [RR ms, 결측 마스크] → rrnet `make_input` 의 3채널
`[ (RR − 기준 평균 RR)/100 ms, 창 안 z-score RR, 결측 마스크 ]`, ±10 자르기. 교사 데이터는 기존 `tacho.npy`, WESAD 는 학생 캐시에서 새로 만든다 (`build_tachograms`).

### 2.2 기준 타코그램

참가자(`profile_key`)마다 기준 구간 [start, end] (`baseline_plan`, 기존과 같음) 에서:
- 중심 c 를 start+150 부터 end−150 까지 10초 간격으로 놓고 각 c 의 타코그램을 만든다 (AdVitam·DROZY·MPD-DF·DD-DB 는 300초라 1개, WESAD Base 는 약 20분이라 여러 개).
- 기준 구간이 300초보다 짧으면 (start+end)/2 를 중심으로 1개 (구간 밖 RR 이 섞임, 해당 참가자 표시).
- 결측 마스크 평균이 0.4 를 넘는 타코그램은 버린다. 하나도 안 남으면 그 참가자는 기준 없음 → 평가에서 빠짐.

## 3. 모델

```
g(·)  = rrnet 인코더: Conv1d(3→16,k7)→BN→ReLU→MaxPool4 → Conv1d(16→32,k5)→…→MaxPool4
        → Conv1d(32→32,k5)→…→MaxPool2 → BiGRU(32) → 시간 평균 → 64차원
g_ref = 그 참가자 기준 타코그램들의 g 평균
d_t   = ‖ W · (g(x_t) − g_ref) ‖₂ ,   W ∈ R^{16×64}
logit = softplus(α) · d_t + b         (방향 없음: 기준과 같으면 거리 0, 멀수록 졸음 쪽)
```
- 기준 평균 RR 채널은 창과 기준 타코그램에 같은 값을 쓴다 → 기준 타코그램의 첫 채널은 0 근처.
- 파라미터: 인코더 약 2만 + W 1,024 + 2.

### 3.1 비교 조건

| ID | 내용 |
| --- | --- |
| B0 | v1 rrnet (기존 oof `p_rrnet`, 한 방향 점수) |
| B1 | dev_core (학습 없음, 요약 특징 이탈 거리) |
| F2 | 요약 특징 z (36차원) 의 학습 거리 ‖W z‖, 스트레스 음성 포함 (인코더 효과 비교용, 초안 1 의 A2) |
| R1 | **rrnet 거리**, 스트레스 음성 없음 |
| R2 | **rrnet 거리 + 스트레스 음성** (본안) |
| R3 | R2 + 같은 참가자 순위 보조 손실 (졸음 창 d > 같은 profile 정상 창 d, 쌍 학습의 R 쌍과 같은 규칙, λ = 0.5) |

### 3.2 학습

- 손실: 창 BCE(logit, y), 가중치 = `sample_weights(dataset, group, y)` (학습 교사 3종). WESAD TSST 창은 데이터셋 하나로 보고 참가자 균등, 총 무게는 교사 데이터셋 하나와 같게 (R2·R3·F2). R3 는 배치마다 R 쌍 64개를 추가로 뽑아 softplus(−(d_a − d_b)) 를 λ 배로 더한다.
- 배치: 창 256개를 가중치에 비례해 뽑는다. 기준 임베딩 g_ref 는 배치에 든 참가자의 기준 타코그램을 같은 인코더로 통과시켜 매번 다시 계산한다 (기울기 흐름).
- AdamW lr 1e-3, weight decay 1e-4. 최대 30 epoch (1 epoch = 학습 창 수 / 256 스텝), 검증: 학습 데이터셋마다 참가자 20% (시드 고정), 검증 가중 BCE 가 5 epoch 동안 안 좋아지면 멈춤.
- 증강: 타코그램 ±10초 이동 (창과 기준 각각 독립). 기준 무효 강제(v1 의 invalid_rate)는 쓰지 않는다.
- 시드 0~4. 점수 = 시드 평균 logit. P = σ(점수).
- F2 는 초안 1 의 설정 (W 8×36, lr 1e-2, 1,500 스텝, 배치 1,024).

### 3.3 LODO

fold 는 교사 4종을 하나씩 뺀 4개. fold k 의 학습 = 나머지 교사 3종 + WESAD 묶음 중 k 번째를 뺀 3묶음의 TSST 창. 시험 = 뺀 교사 데이터셋 + WESAD k 번째 묶음.
WESAD 묶음: 참가자 id 정렬 → `np.random.default_rng(0).permutation` → 4개로 나눔.

| **M1** | 시간 층화 AUROC (`teacher-pair-stage1.md` 8.1, tbin 150초), 교사 4종 평균 — **주 지표** |

재현 확인 (실행 전): B0·B1 의 M1 이 `results/2026-11-11-pair/report_pair.md` 값과 ±0.005 안 (B0 0.611, B1 0.637). 평가 행 조건(기준 타코그램 필요)이 달라 값이 바뀌면 그 차이를 10장에 적고 그 행 기준으로 비교한다.

## 5. 판정 (결과 보기 전 고정)

- **졸음 판별 유지**: R2 (또는 R3) 의 M1 평균 ≥ max(B0, B1) − 0.01
- **스트레스 오경보 개선**: S1 이 B1 보다 낮고 S1 차이 95% 구간 상한 < 0
- **채택**: 두 조건을 모두 만족하는 것 중 M1 이 높은 것. R2·R3 가 M1 0.01 이내면 단순한 R2
- **인코더 효과**: R2 − F2 의 M1 차이 95% 구간 하한 > 0 이면 rrnet 인코더가 요약 특징보다 낫다고 본다
- **스트레스 음성 효과**: R2 − R1 의 S1 차이 95% 구간 상한 < 0
- **미채택 시**: RR 만으로는 졸음과 스트레스를 가를 정보가 부족하다고 보고, CAN 규칙 교차 확인과 PPG 파형(NormWear)·자체 측정으로 넘어간다
