# Unity 개인 조향 기준과 추가 경보 검증

2026년 11월 20일에 Unity 6000.6.9f1의 `DrivingPilot` 씬에서 직선 주행을 12회 자동 조작했다. 목표 속도는 99 km/h였고 기록 속도는 97.93~98.08 km/h였다. Unity에서 속도와 핸들 조향각을 50 Hz로 기록하고, 표본 5개씩 기존 Python 서버의 `on_can`과 `update_steering_alert`에 재생했다. 각 주행 기록에 P01과 P02의 기존 키보드 프로필을 각각 적용했다.

## 개인 프로필별 조향 이탈

| 제어 목표와 유지 시간 | Unity 주행 수 | P01 첫 이탈 | P02 첫 이탈 |
|---|---:|---:|---:|
| 직진, +2.2° 0.55초, +5.2° 0.40초, ±5.2° 0.66초 | 5 | 없음 | 없음 |
| +2.2° 1.15초 | 1 | 0.99초 | 0.99초 |
| +5.2° 0.80·0.82·0.84초, −5.2° 0.82초 | 4 | 각 0.79초 | 없음 |
| ±5.2° 1.08초 | 2 | 각 0.79초 | 각 0.89초 |

목표 각도와 유지 시간은 자동 조작 명령이며, 판정에는 Unity가 기록한 실제 응답을 사용했다. 첫 이탈 시각은 각 주행 기록이 시작된 뒤 서버에서 처음 이탈을 읽은 시각이다.

두 프로필 모두 기준이 있는 +2.2° 조건에서는 판정 시각이 같았다. 5° 구간의 개인 기준은 P01에 있었고, P02는 표본이 부족해 이 주행에서 2° 구간의 지속 조건이 적용됐다. 따라서 ±5.2° 조건에서 관측한 차이에는 프로필별로 사용할 수 있는 각도 구간의 차이가 포함된다.

## 생체 상태와 추가 경보

12개 Unity 기록에 두 프로필과 세 가지 시험용 생체 상태를 조합해 기존 서버의 결합 규칙을 72회 확인했다.

| 시험용 생체 상태 | 결합 시험 수 | 추가 경보 |
|---|---:|---:|
| 정상 | 24 | 0건 |
| 판정 동결 | 24 | 0건 |
| 졸음 확정 | 24 | 조향 이탈이 함께 발생한 10회에서 각각 1건 |

차량 입력은 새 Unity 주행 기록을 사용했다. 생체 상태는 결합 규칙을 확인하기 위해 지정했다. 실제 생체 모델의 졸음 검출 성능, Unity 경보음 재생, 라즈베리 파이에서의 생체·CAN 추가 경보 통합은 검증 범위 밖이다. 파이용 모듈은 별도로 정상 운전 CAN 수집, 개인 기준 생성, 실시간 조향 판정을 지원한다.
