저장된 ECG·PPG 원본 기록으로 기준을 만들고, 기록을 재생하면서 점수와 상태를 새로 계산합니다.

1. 사용자 등록 또는 선택

기준을 저장할 사용자를 정하세요. 기존 사용자도 같은 목록에서 선택합니다.

2. 사용할 기준 선택

기준 준비 방법

저장 기준을 불러오면 계산·저장 단계를 건너뜁니다.

깨어 있는 안정 상태의 기록을 선택하세요. 이후 판정할 기록은 마지막 단계에서 따로 고릅니다.

3. 선택 기록으로 기준 계산

처음 60초를 제외한 이후 5분 구간과 품질을 확인합니다. 준비되면 자동으로 멈춥니다.

4. 계산한 기준 저장

이름은 기준을 구분하는 용도입니다. 기준 수치는 선택한 원본으로 계산됩니다.
