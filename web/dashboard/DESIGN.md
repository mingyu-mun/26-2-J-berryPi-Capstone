# 디자인 결정

방향: 순정 디지털 계기판처럼 정돈된 검정 계열 화면에 절제된 시안 표시선. 데이터가 없을 때도 완성된 대기 화면을 유지한다.

- 기존 화면 감사: 큰 설명 헤더, 반복 카드, 상시 노출된 시연 제어, 개발 필드와 측정값의 혼재를 정리했다.
- 다이얼: DESIGN_VARIANCE 3 / MOTION_INTENSITY 1 / VISUAL_DENSITY 5. 원형 눈금과 중앙 상태를 한 면에 배치하고, 움직임은 사용자 조작과 실제 데이터 변경에 한정했다.
- 공식 디자인 시스템 검토: 문서·업무용 컴포넌트보다 계기판 전용 숫자 위계와 작은 로컬 번들이 적합해 시맨틱 HTML, 네이티브 dialog/details, 자체 SVG 눈금을 사용했다. 특정 자동차 브랜드를 복제하지 않았다.
- 배경은 색조가 있는 #080b0e. 강조는 #69cbd9. 글로우와 고채도 그라데이션, 반복된 3열 카드, 버전 라벨, 가짜 수치와 파형을 사용하지 않는다.
- 기본 화면: 현재 심박, 수신한 최종 상태, 속력, 연결 상태, 실제 파형, 실제 기준 수집 현황과 주요 주행값.
- 상세 접기: 모델 점수, 누적 점수, 품질 가중치, 상태 기록, 교차 확인 근거.
- 별도 설정 창: 실제 Pi 입력, 외부 실시간 연결, 실제 이벤트 파일. 시나리오 생성 버튼은 없다.
- 빈 수치는 중간점 두 개, 미수신 파형은 빈 축과 대기 문구로 표현한다. 경고는 색뿐 아니라 상태명·설명을 함께 표시한다.
- 원문 계약 파일은 수정 없이 보관한다. 제품 HTML/CSS/JS에는 em dash와 내부 모델 버전명이 노출되지 않는다.

자동 검사는 입력 규약, 표시 상태, 시간 공백과 미수신 동작을 확인한다. 실제 기기의 브라우저 및 화면 크기에 따른 시각 검수는 별도다.
