# CAN 실험 최종 정리

## 결론

**속도 기반 감속 탐지는 실차에서 우선 검증할 후보다. 조향각 기반 자동 경고는 이번 프로토타입의 필수 기능에서 제외한다.** 감속은 합성 파일럿 기준을 통과했다. 조향은 시험한 규칙으로 정상 회전, 차로 변경, 회피를 충분히 걸러내지 못했다.

## 실험 타임라인

| 원본 문서 | 실험과 결과 |
|---|---|
| 01–06 · 관측 확보와 시연 | 서울 도심순환·테헤란순환·상암순환에서 코스별 100건씩 총 300건의 SUMO 기반 합성 CAN을 생성했다. 유효 직진과 감속 각 12회가 두 조건이다. 각 코스가 관측 확보율 95%에 도달한 공통 시각은 도로 진입 후 7분 30.3초였다. 전체 확보는 이 시점 295/300, 15분 296/300이었다. 미달 4건은 모두 테헤란순환 혼잡 조건이었다. |
| 07–09 · 재현성과 갱신 | 직진 조향 폭에 초기 갱신 문턱 0.35°를 적용하자 정상 오제안 292/293을 기록했다. 구간 경계 수정과 관측 조건 매칭 이후에도 정상 변동이 컸다. 새 문턱 25.90°의 신규 반복 변화 검출은 4/16이었다. |
| 10–13 · 주행 후 조향 비교 | 비슷한 속도의 직진 12구간을 묶어 짧은 보정량과 반전율을 비교했다. 확대 검증의 합성 반복 변화는 112/112를 검출했다. 0.0584° 문턱은 12구간 통계용이며, 중심 이동평균에는 미래 표본이 포함됐다. |
| 14–19 · 초기 실시간 조향 경고 | 1.5~3초 창, 반전, 연속 초과와 보정 동작 분리를 비교했다. 교차로 연결부가 포함되면서 정상 오알림이 발생했다. 도로 형상으로 이를 제외한 뒤에도 최종 동작 분리 규칙은 반복 보정 18/28 탐지, 정상 직진 10분당 17.07회 경고를 기록했다. |
| 20–22 · 조향·감속 분리 검증 | 합성 CAN 데모에서 계산식이 작동하는지 먼저 확인했다. 변동을 늘린 별도 300건에서 작은 조향 감소 후 큰 보정은 36/60, 큰 감속은 60/60을 탐지했다. |
| 23–24 · 미탐 재생과 조향 규칙 수정 | 신규 300건에서 0.4초 기억으로 31/60에서 33/60으로 증가했다. 다른 300건에 0.8초 창을 추가하자 복귀 전 탐지가 83/150에서 111/150으로 늘었고 대부분 천천히 커지는 조향이었다. 정상 회전과 차로 변경을 구분하는지 확인하도록 평가 질문을 수정했다. |
| 25–26 · 정상 조향과 최종 비교 | 신규 평가 300건과 정상 재생 90분에서 같은 CAN에 도로 정보를 제공하는 조건과 제공하지 않는 조건을 비교했다. 네 규칙 조합 모두 기준에 미달했다. |

각 300건은 목적과 구성 조건이 다른 별도 실험이다. 확보율과 탐지율을 합산하지 않았다.

## 수집과 감속 적용 범위

공도 진입을 0초로 두고 종료된 유효 직진과 감속 관측을 집계한다. 두 항목이 각 12회면 완료하고 15분에 부족하면 부족한 횟수를 표시한다. 8분은 기존 시연 로그의 재생 범위다. 서울 세 코스의 15분 확보율은 각각 100/100, 96/100, 100/100이었다. 코스별 단측 95% 신뢰하한은 모두 95% 아래였다. 실차 공도 진입 판별과 내비게이션 연동은 미검증이다.

감속 검증에서는 합성 운전자 3명의 별도 15분 기준 로그에 35·50·65 km/h 속도대별 감속 관측을 각각 4회 배치했다. 0.1초마다 **(1초 전 속도 − 현재 속도) ÷ 3.6**으로 최근 1초 평균 감속을 계산했다. 비슷한 진입 속도의 기준 이벤트별 최대 평균 감속 중 가장 큰 값에 0.45 m/s²를 더해 경계를 잡았다.

| 감속 항목 | 합성 평가 결과 |
|---|---:|
| 뚜렷하게 강한 감속 | 60/60 탐지 |
| 평소보다 조금 강한 감속 | 12/30 탐지 |
| 비교 상황 오알림 | 0/210 |
| 별도 정상 재생 | 45분 동안 0회 |
| 큰 감속 탐지 사례 지연 중앙값 | 0.80초 |

속도로 감속 강도를 관측했다. 페달 조작과 감속 이유, 실차 탐지율은 평가하지 않았다. 감속 전용으로 수집을 바꿀 경우 속도대별 확보율과 완료 조건을 별도로 확인해야 한다. 위 296/300은 직진과 감속을 모두 요구한 결과다.

## 조향 최종 비교

| 같은 BLF에 적용한 방식 | 목표 조향 복귀 전 탐지 | 정상 오알림 | 정상 재생 10분당 경고 |
|---|---:|---:|---:|
| CAN 단독 · 0.4초 | 53/90 | 120/210 | 10.33회 |
| CAN 단독 · 0.8초 경로 추가 | 55/90 | 123/210 | 10.44회 |
| 시뮬레이터 도로 정보 · 0.4초 | 53/90 | 30/210 | 3.00회 |
| 시뮬레이터 도로 정보 · 0.8초 경로 추가 | 55/90 | 33/210 | 3.11회 |

통과 기준은 복귀 전 탐지 72/90 이상, 정상 오알림 21/210 이하, 좌회전·우회전·차로 변경·회피 각각 3/30 이하였다. CAN 단독은 좌·우회전에서 각각 30/30 경고했다. 도로 정보를 주면 회전과 커브 경고는 0건이 됐지만 직진 도로에서 차로 변경과 회피에 각각 15/30 경고했다. 조향각·속도·직진 상태가 같고 의도만 다른 30쌍에서는 판정이 모두 같았다. 시험한 규칙과 합성 차량 환경의 결과이며, 실제 차선 정보와 조향 보조 개입은 검증하지 않았다.

## PR 포함 범위

**PR에는 이 통합 문서와 실행용 코드 폴더 두 개를 포함한다.** 검토자가 실험 조건, 수치와 채택 판단을 확인하고, 동봉한 표본으로 감속 판정 및 서울 수집 시연을 재현할 수 있게 구성했다.

- 05번 **CAN 베이스라인 관측 확보율 최종 결과**와 06번 **CAN 베이스라인 사용과 시연 계획**의 결론은 수집 절에 반영했다.
- 22번 **CAN 속도 기반 개인 감속 탐지 검증**과 26번 **정상 조향과 개인 조향 변화 구분 실험 결과**의 지표는 각각 최종 결과 표에 반영했다.
- 나머지 단계별 MD는 타임라인으로 요약했다. 원본 26개 MD는 로컬 실험 이력으로 유지한다.
- [01 감속 탐지 코드](01_감속_탐지_코드/README.md)는 개인 감속 기준 구축, 강한 감속·일반 감속 재생, 실행용 표본을 포함한다.
- [02 서울 합성 CAN 시연](02_서울_합성_CAN_시연/README.md)은 세 코스 대표 BLF의 관측 확보 판정과 300건 결과표 집계를 재현한다. 첫 15분으로 기준을 맞춘 서울 샘플의 후반 감속 재생도 제공한다.
- 임시 파일과 전체 합성 BLF는 기존 실험에 보관한다. 실행용 두 폴더에는 시연에 필요한 대표 로그와 결과표만 포함한다.
