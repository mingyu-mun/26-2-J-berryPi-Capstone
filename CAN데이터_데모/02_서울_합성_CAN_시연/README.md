# 서울 합성 CAN 시연

기존 SUMO 기반 서울 로그를 재생하기 위한 폴더다. 두 폴더를 같은 상위 경로에 둔다. 감속 및 CAN 해석 코드는 옆 폴더의 `01_감속_탐지_코드`에서 불러온다. 이 폴더에서 다음을 실행한다.

```powershell
python -m pip install -r "../01_감속_탐지_코드/requirements.txt"
python seoul_replay.py replay
python seoul_replay.py summary
python seoul_replay.py decel --case downtown_1900000
```

| 명령 | 시연 |
|---|---|
| `replay` | 서울 세 샘플 BLF에서 직진·감속 관측 수와 12회씩 충족한 시각을 재계산한다. 도심 278.5초 및 상암 381.5초에 충족하며, 테헤란 혼잡 예시는 15분 진행률 58.33%로 끝까지 미달한다. |
| `summary` | 본실험의 300건 요약 CSV에서 15분 확보 296/300과 세 코스의 공통 95% 도달 시각 450.3초를 재집계한다. |
| `decel` | 서울 샘플의 처음 15분으로 속도대별 기준을 맞추고, 이후 약 5분의 속도에서 경계 초과와 기준 부족 건을 출력한다. 같은 주행 안에서 구간을 나눈 시연이며 실험의 독립 후속 데이터 성능과는 별개다. |

동봉한 서울 로그의 후반부에서는 강한 감속 알림이 없었다. 도심 샘플은 기준이 매칭되지 않은 감속 표본이 572개였다. 경고가 실제로 켜지는 시연에는 옆 폴더의 강한 감속 예제를 사용한다.

`replay`는 동봉된 SUMO 구간 라벨을 사용해 CAN으로 측정값과 품질을 재확인한다. 300개 원본 BLF를 다시 돌리거나 SUMO에서 새 도로 주행을 생성하는 기능은 이 배포본의 재생 범위에 포함되지 않는다. 조향각은 기존 수집 데모의 직진 관측 통계에만 사용한다.
